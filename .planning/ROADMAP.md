# Roadmap

## Now

- Phase 001: Thesis lock and Checkpoint 2
  Outcome: A differentiated DeFi-track pitch, public repository, contract specification, and credible progress update submitted by 2026-07-26.
  Status: Planned

- Phase 002: Settlement contract core
  Outcome: Tested Arc-compatible contract supports independent line-item funding, attestation, challenge, release, dispute, claim, expiry, and refund.
  Status: Planned

## Next

- Phase 003: End-to-end Arc product
  Outcome: Circle wallets, Circle Contracts deployment, Arc Testnet USDC, and a usable web flow complete the golden-path demo.
  Status: Planned

- Phase 004: Hardening and submission
  Outcome: Negative-path UAT, optional bridge integration, public docs, deck, and three-minute demo are complete and submitted one day early.
  Status: Planned

## Later

- Phase 005: Customer validation
  Outcome: Expand the initial hackathon interviews to at least fifteen total, select one corridor, and secure or explicitly fail to secure a design-partner signal.
  Status: Not started

- Phase 006: Production discovery
  Outcome: One corridor has a documented legal/compliance model, licensed-partner path, attestation governance, and bottom-up unit economics.
  Status: Not started

- Phase 007: Pilot
  Outcome: A design partner runs shadow-mode settlement against historical or synthetic invoices before any real-money launch.
  Status: Not started
