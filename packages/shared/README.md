# Shared package

Shared contract ABIs, TypeScript types, fixture invoices, and event/state mappings for the web app and scripts.

- [abi/ParcFiEscrow.json](abi/ParcFiEscrow.json) — generated ABI for `ParcFiEscrow` (regenerate with `forge inspect src/ParcFiEscrow.sol:ParcFiEscrow abi --json` from `contracts/`).
- [fixtures/golden-path-invoice.json](fixtures/golden-path-invoice.json) — the synthetic three-line demo invoice.

TypeScript types and viem bindings are added in Phase 003.
